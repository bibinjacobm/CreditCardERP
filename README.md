# Personal Credit Card ERP

**Manage. Monitor. Optimize.**

A professional, fully offline Windows application for managing all your credit cards in one place — bills, payments, due-date alerts, billing cycles, reports and automatic backups. Your data never leaves your computer.

## Download

👉 Go to **[Releases](../../releases/latest)** and download `CreditCardERP-<version>-Setup.exe`.

Run it — no administrator rights needed. If Windows SmartScreen appears, choose **More info → Run anyway**.

## Updates

The app checks for new versions automatically and installs them in a minute. Your data is backed up first and is always kept.

## Requirements

Windows 10 or 11 (64-bit).
